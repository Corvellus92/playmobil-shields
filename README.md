# Playmobil pajzsok – mobil PWA (v1)

Három csempe soronként. Szürke keret = nincs meg; érintésre zöld = megvan; újabb érintésre szürke. Keresés, szűrés, JSON export/import és helyi mentés. Az alapadatok az [Animobil Shields & Heraldry katalógusából](https://animobil.info/shields/text/wit-toc.html) kézzel rögzített pajzsforma- és azonosító-adatok. A PlaymoDB és Animobil hivatkozások az oldalakra mutatnak; még nem egyedi pajzsadatlap-linkek. A pajzspiktogramok *nem* eredeti termékfotók. A lista a katalógus egy részhalmaza: nem tartalmaz minden matricaváltozatot, alapszínt vagy újabb darabot.

## GitHub Pages telepítés
1. Hozz létre új GitHub repót (például `playmobil-shields`).
2. A ZIP kibontott fájljait közvetlenül a repo gyökerébe töltsd fel.
3. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
4. Az így létrejött HTTPS címet nyisd meg Android Chrome-ban, majd menü → *Hozzáadás a kezdőképernyőhöz* / *Alkalmazás telepítése*.

A kiválasztások az adott böngésző `localStorage` tárhelyén maradnak. Telefoncsere előtt JSON mentés javasolt. A forrásoldalak nem hivatalos rajongói adatbázisok. Ne másolj át képeket engedély nélkül.
